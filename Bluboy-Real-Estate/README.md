# Bluboy Real Estate Company Limited

A simple, responsive real estate landing page made with HTML, CSS and basic JavaScript for a school project.

## Project files

- `index.html` holds the page sections, text, navigation, property examples and contact form.
- `style.css` controls the colours, spacing, cards, layout and how the page changes on smaller screens.
- `script.js` opens the mobile menu and checks the contact form. The form only shows a message; it does not send email.
- `images/` contains the sample property photographs used on the page.

## View the website

Open `index.html` in a web browser. Keep the `images` folder beside the HTML file so the pictures can be found.

## Before sharing

The property details, email, phone number and office address on this page are examples, not real listings or contact details. Replace them with approved information if you use the page beyond this assignment. The photographs are sample images and can also be replaced with images you have permission to use.

## Upload to GitHub

1. Sign in at [github.com](https://github.com) and create a new repository for the project.
2. Open the empty repository and choose **Add file**, then **Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the contents of the `images` folder. Keep the pictures inside a folder named `images`.
4. Add a short message such as `Add real estate website` and select **Commit changes**.

## Publish with Netlify

1. Sign in at [netlify.com](https://www.netlify.com) and choose **Add new site**.
2. Choose **Import an existing project** and connect the GitHub repository you created.
3. For this plain HTML project, leave the build command empty. Set the publish directory to `.` if Netlify asks for one.
4. Select **Deploy site**. Netlify will provide a website link when the upload finishes.

You can also publish by choosing Netlify's manual deploy option and dragging in the whole project folder. Keep the HTML file and its CSS, JavaScript and `images` folder together.
